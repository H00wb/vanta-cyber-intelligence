1. KURULUM
Node.js 24.x kurulu olmalı. Kaynak depoyu klonlayıp klasöründe:
  npm ci
.env.example dosyasını .env.local olarak kopyalayın; kendi Supabase URL ve publishable key değerlerinizi girin.
Supabase SQL Editor'de supabase/migrations/20261007212753_vanta_requests.sql dosyasını yeni kurulumda bir kez çalıştırın. Mevcut teslim projesinde zaten uygulanmıştır.
  npm run build
  npm run start
Yerel adres: http://127.0.0.1:5173 . Başka terminalde test komutları çalıştırılır.
Bu yerel uygulama da ayarladığınız gerçek Supabase projesine yazar.
